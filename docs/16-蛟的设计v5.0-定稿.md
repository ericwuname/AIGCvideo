## 二、找到的最关键一条：蛟的"邪恶"是有出处的

> **"龙通常象征着正义和尊贵，而蛟则代表邪恶，被描述成恶蛟，它往往伴随仇恨诞生，在神话中也多以破坏为主。"**

我之前把它做得像个"庄严的神兽"，方向从一开始就错。**蛟在民间叙事里是害人的东西**——《墨客挥犀》写它"见人先腥涎绕之，即于腰下吮其血，血尽乃止"。

所以它不是"幼年的龙"，是**水里的恶兽**。这决定了整个气质：

| | 龙 | 蛟 |
|---|---|---|
| 象征 | 正义、尊贵 | **邪恶、破坏** |
| 眼睛 | 鼓出 | **凹陷** |
| 表面 | 干燥、威严 | **黏滑、发腥** |
| 姿态 | 腾云 | **贴地爬行、潜行** |
| 角 | 双鹿角分岔 | **无角或单直角** |

## 三、蛟 v5.0 定稿规格

| 部位 | 定义 |
|---|---|
| 体 | 数丈长，**粗壮**（重型蛇躯，不是细长），腹部贴地 |
| 鳞 | **珍珠般密集的硬鳞**，黏滑、发湿 |
| 四肢 | 四足，**前肢宽扁如桨**，后肢短粗 |
| 头 | **猫科头骨结构 + 通体鳞皮、无毛发、无虎纹** |
| 眉间 | **一对交叉突起的肉块**（"蛟"字得名由来） |
| 眼 | **凹陷**，竖瞳 |
| 颈 | **白色花纹** |
| 背 | **暗蓝花纹** |
| 胸 | **赭色** |
| 尾 | 蛇尾，**尾尖有硬刺** |
| 角 | 无（或单只短直角） |
| 配色 | **只用暗浊色**：墨黑、暗青、血褐、赭。**无橘黄、无亮色、无金** |
| 气质 | 邪恶、嗜血、潜行、repulsive |

## 五、三视图这条路，确认走不通（第二次验证）

这是第二次三视图失败了：
- `jiao_v8_turnaround_real` → 蜥蜴标本
- `jiao_v10_turnaround_dark` → **海豹**

**原因**：中立灰底 + 全身完整 + 四足 + 贴地，这个组合在 AI 的认知里最接近"海豹/海狮/娃娃鱼"的标本照。

**结论（已经是第二次验证，写进方法论）：**
- 蛟这类生物的**三视图不可靠，不要指望它**。
- 三视图的作用仅限于"看比例和结构"，**必须容忍它会退化，且不进成片**。
- **真正的定稿靠"环境中的实拍感镜头"**——`jiao_v10_head` 和 `jiao_v10_crawl_dark` 这两张，比任何三视图都更能说明它是什么。

## 六、蛟与墨龙（化龙前后）

| | 蛟 v5.0 | 墨龙 |
|---|---|---|
| 躯干 | 粗壮重型，贴地爬行 | 长躯腾云 |
| 头 | 猫科头骨+全鳞+眉间肉块，小头短吻 | 马首龙须 |
| 角 | 无 | 有鹿角 |
| 眼 | **凹陷** | 微凸 |
| 表面 | 黏滑发腥 | 干燥带光 |
| 色 | 墨黑/暗青/血褐 | 墨黑+青绿虹彩 |
| 气质 | **邪恶、嗜血** | **威严、震慑** |

**同一条东西，渡劫前后的两种状态。** 颜色的基底（墨黑）一致，所以"化龙"成立。
