# 蛟的最终方案：不设计它，只给它露出来的部分

> 日期：2026-10-19 02:45
> 用户第七次反馈原话：「你的这个设计真的是笑死我了，感觉就是豹子一样，然后鱼鳍，鳄鱼一样，太奇怪，太丑了」
> 结论：**六轮"设计完整蛟"全部失败。转向"永不露全貌"。**

---

## 一、我错在哪（诚实复盘）

六轮迭代，我一直在做同一件事：**把蛟的各个器官拼出来，然后给它拍标准照。**

| 轮 | 我的做法 | 结果 |
|---|---|---|
| v1–v3 | dragon + no horns | 鳄鱼 / 怪鱼 |
| v4 | 虎首 + 蛇身 | 头身接缝像两个动物缝在一起 |
| v5–v6 | 盘曲 / 无足 | 巨蛇 / 蛇颈龙 |
| v7–v8 | 汉画像砖走龙 + 写实材质 | 造型跳出来了，但腿太长像恐龙 |
| v9 | 古籍规格拼装（珍珠鳞 + 桨状肢 + 虎首） | 配色花哨像娃娃鱼 |
| v10 | 鳞皮头部 + 暗黑配色 | **豹子头 + 鱼鳍 + 鳄鱼身**（用户："笑死我了"） |

**根因：我在用"生物拼装"的思路做中国神兽。**

把猫科头骨、鱼鳞、桨状肢、蛇尾这些**真实的动物零件**拼在一起，结果必然是一个**解剖学上说不通的拼接怪**——它不是可怕，是滑稽。

**可怕和可笑之间，差的是"可信"。**

---

## 二、转向：不设计它，只给它露出来的部分

电影史上所有成功的"巨兽"，都不是靠"设计得精细"赢的：

- **大白鲨**：全片几乎不给全貌，只有背鳍和一张嘴
- **异形**：永远在阴影和遮挡里
- **克苏鲁**：不可名状，一说清就掉价

**因为观众脑补的，永远比画出来的更可怕。** 一旦给他看清，就只剩下"这设计好不好看"这个问题——而我们的设计，显然不好看。

### 新的工作方式

**不再追求"蛟的三视图 / 完整造型"，改为生产"一组局部镜头"。**

每个局部都是**可拍的、真实的、不需要解释解剖学**的：

| 局部 | 是什么 | 为什么成立 |
|---|---|---|
| 水下的长条暗影 | 一段模糊的形 | **看不清 = 最大恐惧** |
| 一只巨爪插进泥里 | 局部 | 尺度靠泥浆和爪的比例传达 |
| 尾梢带刺扫过水面 | 局部 | 高速瞬间，看不清全貌 |
| 珍珠鳞与黏液特写 | 材质 | 质感本身就是压迫 |
| 半开的嘴与细齿 | 局部 | 不给整张脸 |

**它们剪在一起，观众知道"有个巨大的东西"，但永远凑不出完整形象。**

**全片没有任何一镜能看到蛟的完整形态。**

## 五、这条经验对项目的意义

**这不只是"蛟怎么画"的问题，是关于"AI 能力边界怎么用"的方法论：**

> AI 擅长**材质、局部、光影**（鳞、水、泥、爪、眼、雨），
> AI 不擅长**完整虚构生物的解剖结构**（一给全身就拼错）。
>
> **所以：把镜头语言设计成"只让 AI 画它擅长的部分"，而不是"让 AI 画一个它画不出的整体"。**

这不是妥协，这是**用导演手段绕过技术限制**——而且成片效果更好。
