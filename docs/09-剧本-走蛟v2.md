# 09 · 剧本《走蛟》v2

> 版本：v2（推翻 v1 的叙事骨架与视觉策略，保留"走蛟讨封"内核与两句台词精华）
> 依据：民间"走蛟渡三劫"说（雷劫/滩劫/人劫）＋"蛟以鳄鱼为原型"的目击总结
> 定位：横屏 16:9 · 目标成片 115–120 秒 · 单集 · 写实电影质感 · 可扩展为系列
> 写作日期：2026-10-19

---

## 一、一句话

**一场暴雨里，两个生灵各自渡劫——蛟渡它的千年劫，她渡她的杀父仇。她手里攥着蛟的命，一句话能定它生死，也定她自己。**

---

## 二、主题：渡劫

v1 的题眼是"一句话定它生死，也定她自己"，但**恨的来源没有建立**——她凭什么恨蛟？剧本没说清。
v2 把因果链补死，并把主题收敛为一个字：**劫**。

- 蛟的劫：褪鳞生肢、撞滩、被雷追着劈，最后还要向一个凡人讨一句封正。
- 阿月的劫：昨夜走蛟发大水，她爹撑船去救邻家孩子，被浪吞了，没回来。她恨这条江里的东西。
- 两人在同一个雨夜面对面，**她说"龙"，两个劫同时化解；她说"蛇"，两个劫同时万劫不复。**

她最终说"龙"，不是因为心软，而是她在蛟渡劫的惨状里，看到了她爹——**她爹为救人而伤痕累累的手，和蛟为化龙而崩裂渗血的鳞，是同一种东西。**

---

## 三、人物

**阿月**，18 岁，江南渔家女。粗麻短褐，湿发，手上是撑船磨出的茧。
昨夜走蛟发大水，她爹披蓑衣撑船去接三叔家的娃，再没回来。今夜，她来江边找他。

**蛟**——不露全貌，全片只给四个东西：**鳞、眼、影、光**。这是硬约束，见第七节。

**她爹（仅闪回 + 旁白出现）**——一个撑船的手裂了口的渔夫，去救邻家孩子的人。

---

## 四、民俗设定（三劫，均有出处）

| 劫 | 是什么 | 剧中如何用 |
|---|---|---|
| **天劫 · 雷劫** | 天雷焚身，渡不过灰飞烟灭 | 第三幕的视觉高潮：闪电追着往水里劈 |
| **地劫 · 滩劫** | 褪旧鳞、长四肢，浑身皮肉烂得淌血；撞桥钻滩 | 第二幕的视觉母题：鳞一片片剥落渗血 |
| **人劫 · 封正** | 需人一句口彩："好大一条龙"则成，"好大一条蛇"则千年修为散作血水 | 全片戏剧核心：阿月手握这句封正 |

> 关键证据（写这条是为了堵住"蛟画成鳄鱼"的根因）：
> 民间对蛟的目击总结是"**以鳄鱼为原型，综合蟒蛇、大鱼与牛的特点**"。
> 所以 AI 把蛟画成鳄鱼，不是 bug——它踩中了人类自己脑补的蛟。**结论：蛟的全貌不可拍，必须只拍局部。**

## 五、三幕结构（约 115 秒）

| 幕 | 时长 | 功能 | 情绪 |
|---|---|---|---|
| 一 · 找 | 0–35s | 建立：她来找爹，走蛟害死了爹 | 失落 → 怀疑 |
| 二 · 撞见 | 35–77s | 走蛟渡劫的惨烈 + 讨封规则 + 雷劫开始 | 惧 → 恨 |
| 三 · 抉择 | 77–115s | 雷劫高潮，她手握生杀，最终成全 | 恨 → 不忍 → 放手 |

## 七、视觉母题与 AI 能力规避清单（本剧最高优先）

**能拍的（AI 强项，全部压上）：**
- 鳞片——一片片、渗血、剥落、反光（纹理）
- 斗笠——竹编经纬、血被冲淡（材质）
- 手——茧、裂口、血（人）
- 雨、雷、闪电、云开、金光、水（天气现象）
- 长影、水线、漩涡（暗示）

**不能拍的（AI 稳定崩塌，全部回避）：**
1. 蛟的**头部 / 吻部 / 牙齿 / 全身** → 必成鳄鱼
2. **龙形全身** → 必成喷泉或西方龙
3. 虚构生物的任何**全貌** → 模型先验坍缩

**四样唯一允许的蛟元素：鳞、眼、影、光。** 超出这四个，执行窗口先停，回来问，不要硬拍。

## 八、台词（全片仅两句对白 + 一句回忆 + 一段旁白）

```
爹（回忆，混响）：江水在走蛟，要发大水了……我去接你三叔家的娃，天亮就回。

旁白（苍老男声）：老辈人说，走蛟渡三劫。天劫是雷，地劫是滩，人劫……是讨一句封正。
说它是龙，它就活；说它是蛇，它千年修行，散作一江血水。

阿月（发抖，带恨）：好大一条……
（沉默四秒，只有雷。这是全片最贵的一口气。）
阿月（平静，泪混着雨）：……龙。
```

## 九、钩子（为系列与平台留的口）

镜 15 结尾的"鳞手"是下一集的钩子：**龙没有走远，或者，它记着阿月。**
第二集可从"阿月捡到的那片鳞 / 她爹的蓑衣缠着一根龙须"起笔，进入强冲突线（红果需要）。

## 十、与 v1 的差异（为什么推翻）

| 维度 | v1 | v2 |
|---|---|---|
| 因果链 | 恨无来源（爹死与蛟无因果） | 走蛟发大水→爹死，恨有据 |
| 戏剧核心 | 人劫（讨封）单腿站立 | 天/地/人三劫齐备，雷劫回归 |
| 视觉策略 | 拍蛟（头部/全身）→ 崩成鳄鱼 | 只拍鳞、眼、影、光，全在 AI 强项 |
| 化龙 | 拍龙形 → 崩成喷泉 | 拍现象：金光、雨停、云开 |
| 成全理由 | "她心软了"（抽象） | 爹的手 vs 蛟的鳞同构（具体可见） |
| 结尾 | 余味收场，无钩子 | 鳞手钩子，接得住下一集 |
| 情绪曲线 | 慌→惧→恨→不忍→放手（缺支撑） | 失落→怀疑→惧→恨→不忍→放手，每步有事件 |

## 十一、开工前置（给执行窗口）

1. **先出分镜表审批版**：把 15 镜的轴线/视线/进出画方向补全，交评审，**不要直接开拍**。
2. **资产先行**：环境锚点（江岸村口全景）、阿月三视图 v1.1（睁眼+粗麻质地）、"蛟鳞"母版（一片鳞的特写作锚点）、"金色竖瞳"母版。
3. **每镜 3 选 1**，涉及"鳞/眼/影/光"的镜头全部先出静帧交评审目验，确认不是鳄鱼再进视频。
