## 二、关键认知：为什么前几轮全在打转

我一直在用**动物学描述**在做蛟——"长颈的巨蛇"、"四足的水兽"。这种描述会必然落进真实动物的模板：

| 描述组合 | AI 落到 |
|---|---|
| 长颈 + 水 | **蛇颈龙** |
| 粗壮 + 四短足 + 水 | **鳄鱼** |
| 长躯 + 无足 | **巨蛇** |
| 长躯 + 横向构图 | "特别长的一条虫"（用户批评） |

**这不是提示词问题，是描述范式的问题。**

换用**中国古典造型语言**（汉画像砖的"走龙"）之后，一次就跳出来了：

> S 形躯干 + 小头短吻 + 细颈粗身 + 四肢外张的行走姿态 + 细长尾 + 无翼

这个造型本身就是中国古人画"龙/蛟"的程式，不是任何一种真实动物的姿态。

## 三、最终采用的蛟

### 造型规格（AST-CREATURE-001 v4.0）

| 项 | 定义 |
|---|---|
| 躯干 | **S 形**（不是直条，不是横向拉长） |
| 头 | **小头、短钝吻**（不是马头龙、不是鳄鱼头、不是虎头） |
| 颈 | 细，与粗躯干形成对比 |
| 四肢 | 四足，外张，行走/踏水姿态 |

| 角 | 无（视频/成片镜头里不出现角） |
| 材质 | 墨黑鳞 + 珠状疙瘩，湿、挂泥、带伤渗血 |

## 四、一条重要经验：三视图不能当素材

`v8_turnaround_real` 三视图虽然三个角度齐全，但**明显退化成"蜥蜴标本/树脂模型"**。

原因：**中立灰底 + 全身完整呈现**这种画法，本身就暗示"这是一件标本"。

**结论：**
- **三视图** → 用来锁比例、锁结构，作**设计锚**，不进成片
- **成片素材** → 必须在真实环境里、带光带雨带泥，才会"活"

这条对所有角色/生物资产都成立。

## 五、与墨龙的协调

现在有两条生物线：

| | 蛟（渡劫前） | 墨龙（渡劫后） |
|---|---|---|
| 造型 | 走龙式 S 形躯干、小头短吻、**无角** | 东方龙，马首龙须、**有角** |
| 颜色 | 墨黑 + 青绿虹彩 | 墨黑 + 青绿虹彩 |
| 状态 | 湿、挂泥、带伤、狼狈 | 威严、盘云、鳞缝透光 |
| 关系 | **同一具身体的两个阶段** | |

**颜色一致，造型升级** —— 这样"化龙"才成立：不是换了一条龙，是同一条东西长出了角、抬起了头、腾了云。
