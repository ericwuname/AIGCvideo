## 二、28 张实测（V1–V5），有效结论

### 2.1 图生图（I2I）在这里是拖累，不是帮助

V1 用 `2.jpeg` 做 I2I 出 9 张，只有 2 张合格；而这 2 张恰恰**没用参考图**（T2I），且出图只要 11 秒（I2I 要 46–60 秒）。

原因：`2.jpeg` 是**场景照**不是**角色设定照**。I2I 继承了它的氛围和构图，但没有继承"这一只"，9 张出来是 9 只不同的蛟。而且参考图会压过 prompt 的构图指令（写"眼睛微距"出全景、写"脊背破水"还在水下）。

**规则：角色资产一律 T2I；只有"环境/氛围"可以 I2I。**

### 2.2 三类失败模式及根因

| 现象 | 根因 | 对策 |
|---|---|---|
| 画面中心凭空长出**白色毛茸茸小兽**（有的还戴金冠） | 负面词 `no fur / not cute / not a pet` 被当成正面提示（反向召唤）；参考图里的白骨被理解成"有个小活物" | 删掉这类负面词，改成正面锁 `the frame contains only this one creature, nothing else alive` |
| 写 `a crown of spines` → 画出**一顶金冠** | 词面直译 | 禁用 `crown` 一词，改 `a crest of tapered bony spines` |
| 头部出现**眼镜蛇兜帽**（颈侧展开） | "蛇身 + 头冠"组合把模型带向眼镜蛇 | 明写 `the neck is thick and does not flare out` |

### 2.3 根本矛盾：写实 vs 东方龙，是两个互斥吸引点

- 说"写实" → 模型滑向**鳄鱼 / 科莫多龙**（真实存在的爬行类）
- 说"东方龙" → 模型滑向**插画**（用户说的"太抽象"）

V2 全部滑向鳄鱼：方头、满嘴獠牙、四腿、无龙须无鬃毛。

**破法（V3 验证有效）**：把"摄影语言"**放在最后**，把"概念锚 + 解剖判据"放最前。顺序是：
1. 概念锚：`an Eastern dragon, a Chinese dragon — NOT a lizard and NOT a crocodile`
2. 解剖判据：逐条写"中国龙有、鳄鱼没有"的特征
3. 摄影语言：`live-action film still / anamorphic / practical lighting / film grain`

### 2.4 关键发现：我在"纠正"的，其实是正统特征

V4 我把"牛耳、驼吻"当缺陷去负面压制 → 越压越明显（反向召唤）。

查证：《尔雅翼》《本草纲目》载**龙九似**——**角似鹿、头似驼、眼似兔、项似蛇、腹似蜃、鳞似鱼、爪似鹰、掌似虎、耳似牛**。

**牛耳和驼吻是正宗中国龙特征，不是 bug。**

但 V5 直接照抄"九似"清单反而更差：`head like a camel` 被理解成驼脸/牛脸，牙齿外露、龙须消失。**九似是文化正解，不是 prompt 配方。**

> 可作为"设定依据"写进剧本/宣发，不要作为生成 prompt。

## 三、定案：V3 配方（已实测同时成立"写实 + 东方龙"）

### 3.1 造型规格

| 部位 | 规格 |
|---|---|
| 体形 | 单条粗壮蛇形长躯，盘曲时如三层环，尾端收成鳍状 |
| 体粗 | 约等于一人高（提供尺度参照） |
| 四肢 | **仅两前肢**，短而有力，收在胸前；**无后腿**（须显式写 `no hind legs at all`） |
| 头骨 | 长而窄，向前收细；**吻端微微上翻，鼻孔在最前端** |
| 口 | **紧闭，唇线一条长直线，不露牙** |
| 龙须 | 上颌两侧各一根长而飘的须，向后延伸远超头部 |
| 髯 | 下颌垂长毛 |
| 鬃 | 头后沿颈背披长毛 |
| 角 | **两根后掠的分枝鹿角**，明显分叉 |
| 眉 | 眉骨厚重外突 |
| 眼 | 小而深陷，淡琥珀色，竖瞳 |
| 鳞 | 石板黑（slate-black）+ 苔绿锈色（moss-green patina），湿润、哑光、鳞缝积淤 |
| 禁忌色 | 金色（祥瑞感）、鲜绿/翡翠色（卡通感） |

### 3.2 Prompt 结构（三段式，顺序不可换）

```
[1 概念锚]  The head of an Eastern dragon, a Chinese dragon — NOT a lizard and NOT a crocodile.
[2 解剖判据] Anatomy, precisely: ... (逐条,见 3.1)
[3 摄影语言] Photorealistic live-action film still from a feature film, a real animatronic creature
            photographed on set with practical lighting. Anamorphic lens, extremely shallow depth of
            field, fine natural film grain, desaturated cold teal-black grade, every scale a wet
            physical plate with silt in the seams.
```

### 3.3 固定负面段

```
no crocodile, no alligator, no komodo dragon, no monitor lizard, no dinosaur, no godzilla,
no t-rex, no iguana, no snake head, no exposed teeth, no fangs, no open mouth,
no square snout, no boxy skull, no four legs, no long upright neck, no wyvern,
no wings, no feathers, no fur, no headdress, no crown, no jewelry, no ornament,
no bright green, no emerald, no neon, no cartoon, no anime, no illustration, no concept art,
no digital painting, no 3d render, no CG, no plastic, no text, no watermark
```

**注意：不要压 `no cow ear / no camel head`**（九似特征，越压越冒）。

## 五、下一轮要注意的

1. **"不露正脸"的镜头质量最稳定**——`real2_rear` / `real2_ridge` 一次就成，且气势最足。分镜里应大量使用：只给躯干、脊背、爪、剪影、雨幕里的轮廓。
2. **正脸只在情绪最高点给一次。** 给多了，观众会开始审视"这龙长得对不对"，而不是"这龙可不可怕"。这是怪兽片的基本纪律（大白鲨只给背鳍和嘴）。
3. **生成速度与质量无关**：T2I 12 秒出的图，质量高于 I2I 55 秒出的。不要拿耗时当质量指标。
4. **`2.jpeg` 里的铁链元素是笔意外之财**——"蛟被镇在江底"是一个极强的开场钩子，比原剧本"蛟走水化龙"更有压迫感。是否加进剧本，待定。

## 六、追加：身体结构修正（V6/V7，据用户给的 `3.png`）

### 6.1 用户指出的问题

> `real3_body` 这个图我觉得这个身体比例就不太对，不知道尾巴是从哪里出来的，其他的图也有类似的情况…我觉得这样子比较正常，你的生成图的身体不合常理。

不是比例数值错，是**结构不可读**：我做成了一盘绕三圈、彼此穿插遮挡的绳圈，头/身/尾无法用一条线追踪。

### 6.2 `3.png` 给出的结构规范（已采纳）

| 项 | 规范 |
|---|---|
| 躯干 | **一条 S 形连续长躯**，头→颈→躯干→尾一眼可追踪，**身体绝不自我穿插** |
| 腿 | **四条短腿**，前对在颈后，后对在体后约 2/3 处，各四趾弯爪 |
| 背棘 | 从颅顶沿整条脊柱到尾，**连续不断** |
| 尾 | 约占全长 1/3，逐级收细，末端**一片小扁鳍** |
| 粗细 | 躯干粗细基本均匀后逐级收细，**不是胸腹鼓胀 + 颈部细长** |
| 配色 | 黑鳞 + 暗红腹甲 + 尾鳍暗青 |

**⚠️ 推翻此前"仅两前肢、无后腿"的设定**——那是据 `1.png` 定的，错了。蛟是四足。

### 6.3 I2I 二次验证失败

用 `3.png` 做 I2I（要求"保留结构、改成写实渲染"）：
- 结构确实保住了（四足、S 曲线、尾鳍都对）
- **但画风也保住了**（仍是插画/CG），还吸进了 `3.png` 尾鳍的青色，长出**绿色荧光**
- 结论二次确认：**I2I 保结构的同时必然保画风，不可用于"换风格"**

### 6.4 新发现：结构描述过长 → 模型进入"建模思维"

V6 我把结构写成 `PROPORTION AND STRUCTURE, stated precisely: ...` 一大段 → 出图像 3D 渲染/塑料模型。
V3 的脸之所以写实，是因为那一段全是**材质词**（wet / dull / silt / patina）。

**规则：结构只写必要项（短），材质描述放最后压轴。**

### 6.5 新发现：CG 感的头号病根是"太均匀"

真实动物没有一块皮肤是均匀的。加下面这组词能显著打掉模型感：

```
the tone is patchy and mottled / some plates sun-bleached pale / some stained rust-brown /
some missing entirely leaving raw grey hide / algae growing thickly along one flank and not the other /
old scars and healed gouges crossing the plates at random angles /
some areas slick and wet, other areas dull and dry with dried silt crusted in the seams /
individual scales vary in size and shape / the mane matted in wet rats' tails, not brushed /
nothing about the creature is symmetrical or clean
```

再加**摄影机缺陷**：`imperfect out-of-focus falloff / slight chromatic aberration at frame edges / a few specks of dust and water on the lens / visible sensor noise in the shadows`。

## 七、追加：眼神犀利化（V8–V10，据用户「眼神太和善了，不够犀利」）

### 7.1 病根：我自己写的一句 prompt

V3 那版照「龙九似」写了 `eyes like a rabbit's, small and round`。
**兔子眼 = 圆、软、无害 → 直接就是"和善"的来源。**（九似不能进 prompt，再添一例）

### 7.2 "犀利"在生成模型里是具体视觉信号，不是形容词

按重要性排序：

| 信号 | 说明 |
|---|---|
| **① 上眼睑压低，只留一条窄缝** | 反派通用眼型，最关键 |
| ② 眉骨前突，把眼窝罩进阴影 | |
| ③ **竖瞳**（不是圆瞳） | 必须写成"一根黑色竖针"，不能只写 vertical slit |
| ④ 外眼角上挑 | |
| ⑤ 眼周是裸露湿皮，无毛无睫毛 | |
| ⑥ 不露眼白 | |
| ⑦ **嘴角下垂、上唇绷紧** | 此前漏掉的硬信号 |

### 7.3 三次失败与一次成功

- `real8_eye_macro`（V8）/ `real9_eye_macro`（V9）→ **单拍眼球，出了圆瞳**，且是黄绿色蜥蜴皮。失败 3 次。
- `real9_eye_brow`（V9）→ **成功**：紧裁"眼 + 眉弓 + 嘴角"，出真竖瞳、窄眼缝、眉骨阴影。

差别在**构图上下文**：单拍眼球时，龙的全套锚点（角/须/鬃/体）全部缺席，模型手里只剩"鳄鱼/蜥蜴"这一个真实先验，于是画成鳄鱼。

### 7.4 ⭐ 核心规律：离"整条龙"越远，越吸附鳄鱼

这是「写实 vs 东方龙」矛盾在**景别维度**上的再现：

```
景别越近（局部/微距） → 龙的身份锚点越少 → 越吸附鳄鱼/蜥蜴（唯一的真实先验）
景别越远（整条/全局） → 龙的身份锚点越多 → 越容易成立"东方龙"
```

**推论（直接影响分镜）：**
- **"犀利"要放在带角/须/鬃的整头近景里做**，不能靠眼部微距。
- **眼部微距只能当 0.3–0.5 秒的插入镜头**，一闪而过，观众来不及审视它是不是鳄鱼。
- 同理，任何"只拍一个局部"的镜头都要**额外带一点身份符号进画**（一根角、一段鬃、一片背棘），否则必滑。
