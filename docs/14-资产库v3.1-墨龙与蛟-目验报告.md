## 一、第一条纠正的验证：蛟能不能生成

**能。** 之前我判"画不出来"是错的——错在方法和判断范围。

### 失败路径（jiao_no_horn 组，已废弃）

用 `dragon + no horns, no antlers, smooth head` → **退化成带獠牙的怪鱼或鳄鱼**。

根因：**用"dragon 加否定"的写法，模型只能在"龙"和"鳄鱼"两个吸附点之间选，去掉龙的特征就掉到鳄鱼。**

### 成功路径（jiao_v3 组，4/4 可用）

改成**直接描述形体**，不提 dragon：

```
colossal long-necked water serpent / smooth hornless skull /
serpentine neck / ridge of bony spines down its back /
slate-grey and black wet scales / no wings, no fins, no legs visible
```

| 资产 | 评级 | 结论 |
|---|---|---|
| `jiao_v3_b` | ★★★ **最佳** | 巨大躯干拱出水面，脊刺排列，不给头尾，水花。**庞然大物感最强** |
| `jiao_v3_d` | ★★★ 好 | 远观长躯如山脉蜿蜒，尺度感极强 |
| `jiao_v3_a` | ★★ 好 | 长颈无角脊刺，成立，略偏蛇颈龙 |
| `jiao_v3_c` | ★★ 好 | 低角度伏水，潜伏感强 |
| `jiao_v2_b/c` | ✗ 废 | 明确是鳄鱼（水下头、侧身头） |

### ⭐ 结论性配方（写进方法论）

> **蛟 = 无角 + 脊刺 + 长躯侧影 + 不给头部特写。**
>
> 一拍"正面头部"就变鳄鱼；拍"长躯侧影 + 脊刺 + 无角"，观众的认知是"巨大的水怪"，不会认成鳄鱼。

**对剧本的影响**：镜 3、镜 6 都可以拍蛟（用 v3_b/d），镜 7 的眼特写用 `AST-CREATURE-002_eye_exhausted`，唯独**不要拍蛟的正面头部**。

## 二、第二条纠正的验证：龙该是什么颜色

用户说金鳞太祥瑞，**这个判断有明确的传统文化依据**。

### 五色龙与五行（考据）

| 龙 | 方位 | 五行 | 属性 |
|---|---|---|---|
| 青龙 | 东 | 木 | 祥瑞、生机、最常见 |
| 赤龙 | 南 | 火 | 暴躁、好战、主旱 |
| 白龙 | 西 | 金 | 温顺、战力低 |
| **黑龙** | **北** | **水** | **掌水域、呼风唤雨、性格暴躁、能控洪水、"据说黑龙最凶"** |
| 金龙 | 中 | 土 | **帝王之色、九五至尊、专属皇帝** |

**推论：走蛟发生在暴雨、洪水、渡劫的语境里，这是"水"的事，龙该是黑/青黑，不是金。** 金龙是一出生就当了皇帝，气质完全错位。

《山海经》里"苍龙"本就是**青黑色**，不是金色。

## 三、关键对比：金 vs 墨

| 维度 | 金龙（已弃） | 墨龙（采用） |
|---|---|---|
| 气质 | 祥瑞、帝王、装饰性 | 阴沉、野性、 wounded |
| 与"走蛟"语境的匹配 | ✗ 完全不符 | ✓ 水属、洪水、最凶 |
| 与暴雨夜的对比 | 亮金 vs 暗底，反差大但"假" | 墨黑 vs 暗底，靠**边缘的青绿虹彩**出层次 |
| 与真实感的距离 | 像手办、像年画 | 像真的动物 |

**保留一个例外**：墨龙配**金色竖瞳**（`AST-CREATURE-002_eye_exhausted`）。黑鳞 + 金瞳的对比才是"妖异"，不是"祥瑞"。
