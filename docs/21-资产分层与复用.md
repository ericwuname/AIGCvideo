# 21 · 资产分层与复用（对用户提议的重构）

> 日期：2026-10-19
> 触发：用户提议在 ID/EXP/POSE/COST 之外，再加 **武器、饰品、发型、年龄、性别、技能、特效** 七个模组，问「这样分可不可以，有没有更好的拆法，把复用性用到极致」

---

## 一、先说结论

**方向对，但七个模组不能并列。** 它们混了四种性质完全不同的东西：

| 你的提议 | 本质是什么 | 判断 |
|---|---|---|
| 发型 | 可换装的一层 | ✅ 独立成层，而且很值钱 |
| 饰品 | 可换装的一层 | ✅ 独立成层 |
| 武器 | 可换装的一层（有握持关系） | ✅ 独立成层，但归"道具"大类 |
| 年龄 | **角色基底参数**，不是模组 | ⚠️ 见下 |
| 性别 | **角色基底参数**，不是模组 | ⚠️ 见下 |
| 技能 | = 姿态 + 动作 + 特效的**复合** | ⚠️ 不单列，否则和 POSE/MOT/FX 重叠 |
| 特效 | **不属于角色**，是画面层 | ✅ 要建，但必须放在角色体系之外 |

**为什么"年龄/性别"不能做成模组：**
一个人不会今天是 25 岁明天变 60 岁。年龄和性别是"这个人之所以是他"的**前提**，不是可以往上叠的配件。
如果做成模组，会出现"给年轻人加年龄模组"这种荒唐操作，而且必然把脸改掉。

**正确做法：做成"基底模板"。** 需要老人就直接选 `老人基底`，不是给青年加年龄。
即：**基底有几种（青年男/青年女/中年男/老年女/孩子…），不是模组有几种。**

**为什么"技能"不单列：**
"技能"这个词描述的不是一个视觉单元，而是三个单元的复合：
`起手姿态（POSE）+ 动作过程（MOT）+ 效果（FX）`
龙的"雷" = 抬头蓄力（POSE）+ 甩头（MOT）+ 电弧（FX）。
单列"技能模组"会让这三个东西重复存两份。

---

## 二、更好的拆法：四层

按 **"什么在变 / 变了算谁 / 能不能跨角色共用"** 三个轴来分。

```
第 1 层  BASE    角色基底   —— 不变。一个人一套，不跨角色共用
第 2 层  OVERLAY 可换装层   —— 正交可组合。全部可跨角色共用
第 3 层  PERF    表演层     —— 正交可组合。角色专属
第 4 层  FX      画面效果层 —— 不属于角色。全片共用，参数化
```

---

### 第 1 层 · BASE 角色基底（不变）

| 资产 | 说明 |
|---|---|
| `BASE-<ROLE>-face` | 脸定妆（唯一真源，所有派生图的 I2I 锚点） |
| `BASE-<ROLE>-body` | 体型与骨架（身高、肩宽、胖瘦、驼背程度） |
| `BASE-<ROLE>-sheet` | 三视图（正/侧/背），用于判断"是不是同一个人" |

**年龄、性别在这里定死**，通过选择不同的基底实现：

| 基底模板 | 用于 |
|---|---|
| `young_female` | 阿月 |
| `old_female` | 灶前老妇 |
| `prime_male` | 渔夫、汉子 |
| `child` | 妇人怀里的孩子 |

> **一个角色 = 1 个基底模板 + 1 张脸定妆。换模板就是换一个人，不是叠模组。**

---

### 第 2 层 · OVERLAY 可换装层（正交，全部可跨角色共用）

这是**复用率的主战场**。六个维度，互相独立：

| 维度 | 前缀 | 内容 | 为什么值钱 |
|---|---|---|---|
| 服饰 | `COST` | 短褐/蓑衣/长衫/裙；含面料干湿 | 决定身份与年代感 |
| 发型 | `HAIR` | 干/湿/散/束/被雨打塌/沾草屑 | **湿与干判若两人**，必须分开建 |
| 道具 | `PROP` | 斗笠、竹担、绳、渔网、灯笼、碗 | 交代职业与生活 |
| 武器 | `WEAPON` | 鱼叉、柴刀、棍 | 道具的**功能子类**，需单独出图，因为要解决"手握在哪" |
| 饰品 | `ADORN` | 耳环、发簪、绳结、护身符、补丁 | 最便宜的"个体差异"来源 |
| 状态 | `STATE` | 湿透/泥污/血迹/伤痕/疲惫 | **投入产出比最高的一层** |

**为什么 `STATE` 最划算：** 一套"湿透+泥污"可以套到**所有角色 × 所有服饰 × 所有发型**上。做一层，全局受益。

**关键纪律（否则拼不上）：**
- `WEAPON` 与 `PROP` 不能只画"物件本身"，必须画**手持关系**——手怎么握、握在哪个位置、指节角度。否则拼装时东西会飘在手外面。
- `COST` 必须有 `detail` 面料特写，否则衣服会漂成"好看的古代衣服"。

---

### 第 3 层 · PERF 表演层（角色专属）

| 资产 | 数量 | 说明 |
|---|---|---|
| `EXP` 表情组 | 8 | 平静/惊恐/恨/不敢信/决意/悲痛/麻木/惊觉 |
| `POSE` 姿态组 | 6 | 每张必须能回答"他为什么在这里" |
| `MOT` 动作模组 | 6 | 回头/被掀退/涉水/跪下/屏息/伸手 |

**技能不单列**，用 `POSE + MOT + FX` 组合表达。

---

### 第 4 层 · FX 画面效果层（不属于角色）

| 资产 | 参数 |
|---|---|
| `FX-rain` | 强度 / 角度 / 密度 / 尺度分层 |
| `FX-mist` `FX-splash` `FX-wave` | 同上 |
| `FX-lightning` | 频次 / 亮度 / 时长（2–4 帧） |
| `FX-glow` `FX-dust` | 同上 |

**关键：FX 不做成"十种雨"，而是做成"一个雨系统 + 一组参数"。**
十个雨版本 = 维护十份；一个参数化系统 = 一次做好，全片复用。

## 三、复用率到底能到多少（算给你看）

假设一集需要"3 个角色、在 4 个场景、有 5 种状态"：

**朴素做法（每个镜头单独出图）**
20 个镜头 × 3 次重试 = **60 张图**，且每一张都是一次性的,不能复用。

**分层做法（各层单独建库，组合拼装）**
```
BASE      3 个角色 × 3 张（脸/体型/三视图）  =  9
OVERLAY   5 服饰 + 4 发型 + 6 道具 + 4 饰品 + 3 状态 = 22
PERF      3 角色 × (8 表情 + 6 姿态)         = 42
FX        1 套参数化雨 + 3 个其他            =  4
                                        合计 = 77 张
```
**纸面上可组合出 3×5×4×6×4×3 = 4320 种造型**，而只花了 77 张图的成本。

> 但 **4320 是纸面数字，实际用不到**——因为下面这条纪律。

## 四、必须遵守的一条工程纪律（否则纸面数字是假的）

**每叠一层 I2I，脸就漂一点。**

实测经验：叠 **3 层以内**可控；超过 3 层，"同一个人"就保不住了。

所以正确的用法不是"每帧都现场叠五层"，而是：

> **组合发生在"造型定妆"这一级，不是发生在每一帧。**

流程：
```
1. 基底 + 服饰 + 发型 + 状态  →  生成"造型定妆"（一个角色在特定剧情状态下的标准造型）
2. 人工确认"这就是他/她" → 锁定
3. 之后这个造型内，只换 EXP 和 POSE（这两层不改变身份）
4. 换造型（换衣/换湿透程度）才回到第 1 步
```

**即：`造型定妆` 是组合爆炸的产物，也是后续所有镜头的锚点。**
一个角色一集通常只需要 **1–3 个造型定妆**（如"干燥时""湿透时""带伤时"）。

## 五、目录结构（共享 vs 专属）

```
assets/
  shared/                  ← 跨角色共用，复用率最高
    costume/   COST-<语义>-<序号>
    hair/      HAIR-<语义>-<序号>
    prop/      PROP-<语义>-<序号>
    weapon/    WEAPON-<语义>-<序号>
    adorn/     ADORN-<语义>-<序号>
    state/     STATE-<语义>-<序号>
    fx/        FX-<语义>-<序号>
  char/<ROLE>/             ← 角色专属
    base/      BASE-<ROLE>-face / -body / -sheet
    look/      LOOK-<ROLE>-<场景语义>     （造型定妆，组合的产物）
    exp/       EXP-<ROLE>-<序号>_<语义>
    pose/      POSE-<ROLE>-<序号>_<语义>
    mot/       MOT-<ROLE>-<序号>_<语义>.mp4
```

**判断标准：这个东西换了角色还成立吗？**
成立 → `shared/`；不成立 → `char/<ROLE>/`。
（斗笠给谁都成立；阿月的脸只属于阿月。）

## 六、把复用做到极致的五条

1. **状态层优先做。** 一套"湿透+泥污"套全局，收益率最高。
2. **道具画"手持关系"，不画"物件本体"。** 否则拼不上。
3. **表情做成"中性基底 + 7 个差分"。** 第一张出中性，其余七张都以它为参考，漂移最小。
4. **FX 参数化，不要版本化。** 一个雨系统 + 参数，不要十个雨文件。
5. **默认允许水平镜像**（免费 ×2）。但有三类不能镜像：**文字、持械的手（左右手不同）、有左右之分的服饰**。

**新增建议（你没提但很值钱的）：**
