## 一、最重要的一条结论（先说这个）

**AI 画不出"无角的蛟"。**

我按剧本要求生成无角蛟，prompt 里明确 `no horns, no antlers, smooth head`，负面词也压死了。结果：

- 有角时 → 出来的是**标准的东方龙**（master_A/C/E，形态准确）
- 去角后 → 直接退化成**鳄鱼 / 带獠牙的怪鱼**（jiao_head，彻底失败）

**这说明模型的概念空间里没有"蛟"这个中间态。** 它只有"龙"和"鳄鱼"两个吸附点。这不是 prompt 能解决的。

### 连带后果：剧本的视觉标记失效

剧本第八节写"'无角→有角'是化龙的视觉标记"。**这一条在技术上执行不了。**

### 三个替代方案（需要拍板）

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | 渡劫前的镜头**完全不拍头**，只拍脊背/鳞/影/光。化龙也不用角，用**金光破水 + 穿云长躯 + 龙吟**表现 | 丢掉"角"这个民俗细节，但画面成立 |
| B | 接受渡劫前也有角（弱化民俗考据） | 与"蛟无角"的设定冲突，但视觉统一 |
| C | 用 v1 的做法：不拍生物，只拍现象（水柱/光柱） | 最安全，但"震撼"打折 |

**我倾向 A。** 理由：这一轮生成的脊背图（master_D、jiao_ridge）已经证明——**没有头的龙，比有头的龙更有压迫感**。观众怕的是"不知道那是什么"。
