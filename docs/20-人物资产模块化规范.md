# 20 · 人物资产模块化规范（表情组 / 动作组 / 服饰组 / 动作模组）

> 日期：2026-10-19
> 触发：用户「人物表现、动作、神态、服饰不够，是不是可以把不同情况下的动作图组、表情图组、衣服图组拆开做，再组后拼装；动作模组能不能也拆成资产」
> 结论：**能拆，而且必须拆。** 但要先认清一件事，否则会白做。

---

## 一、先纠正一个常见误解（很重要）

**图片资产不能"替代"视频，它的作用是让每一次视频调用都命中。**

视频配额 500 秒/天，一次调用 5 秒 = 一天只有 **100 次机会**。
而一条 90 秒的短片大约需要 20 个镜头。也就是说：
- 如果每个镜头试 3 次，一集就要 60 次调用 = 300 秒，**一天只够拍一集，且没有余量试错**
- 如果每个镜头**一次命中**，一集只要 20 次 = 100 秒

**图片资产（4000 张/天）的价值就在这里：**
把"这镜该长什么样"在**图**上试到位（首帧、表情、姿态、服装、构图、光位），
让视频那一调用**只负责动起来**，不负责"猜对不对"。

> 一句话：**图是用来消除不确定性的，视频是用来买时间的。**

## 二、四类资产的定义与分工

| 类别 | 形态 | 数量/角色 | 作用 | 配额成本 |
|---|---|---|---|---|
| **ID 定妆** | 图 | 1 | 全角色唯一真源，所有派生图都以它为 I2I 参考 | 0 |
| **EXP 表情组** | 图 | 8 | 决定"这一刻他什么心理" | 0 |
| **POSE 动作组** | 图 | 6–8 | 决定"这一刻他在做什么" | 0 |
| **COST 服饰组** | 图 | 4 | 决定"他是谁、什么身份、湿到什么程度" | 0 |
| **MOT 动作模组** | 视频 | 6–10 | 可复用的运动片段 | **贵（每个 4–6s）** |

**EXP × POSE 的组合 = 一个镜头的"内容"**，COST 决定一致性，MOT 决定运动。

## 三、命名规范

```
assets/char/<ROLE>/
  ID/     ID-<ROLE>-01.png
  EXP/    EXP-<ROLE>-<序号>_<语义>.png
  POSE/   POSE-<ROLE>-<序号>_<语义>.png
  COST/   COST-<ROLE>-<序号>_<语义>.png
  MOT/    MOT-<ROLE>-<序号>_<语义>.mp4
```

ROLE 用大写英文：`AYUE` / `FISHER` / `OLDWOMAN` / `MOTHER` / `OLDMAN`
序号两位，语义用英文小写。例：`EXP-AYUE-03_hatred`、`POSE-AYUE-04_recoil`

## 四、表情组（EXP）标准清单 · 8 个

不是"喜怒哀乐"这种笼统分类，而是**本剧真正会用到的 8 个心理瞬间**：

| # | 语义 | 定义（可写进 prompt 的判据） |
|---|---|---|
| 01 | `calm` | 完全静止，嘴闭，眼神落在画外某个不具体的地方，下颌放松 |
| 02 | `terror` | 眼睛睁大露白，嘴唇微张，呼吸卡在喉咙里，整个人僵住 |
| 03 | `hatred` | 下颌咬紧，嘴角**向下压**，眉压得很低，眼睛眯起来，绝对不笑 |
| 04 | `doubt` | 不敢信：眉梢微抬又挤在一起，头偏一点，嘴唇抿薄，眼神在找解释 |
| 05 | `resolve` | 闭眼将睁，睫毛湿，面部肌肉松开，嘴唇几乎不动，一道泪痕 |
| 06 | `grief` | 面部塌下来，眉心向上抽，嘴张开一点，泪混着雨，忍着不出声 |
| 07 | `numb` | 空、松，眼神失焦，什么都没看见，嘴微张，像是停止了思考 |
| 08 | `startle` | 头刚转过来，眼睛还没聚焦，眉抬起，嘴唇分开——反应的**第一瞬间** |

> **验收标准**：八个表情并排看，**是同一个人**，且**不看标签也能认出是哪个情绪**。
> 只有一项成立都算失败。

## 五、动作组（POSE）标准清单 · 6 个

动作组要解决的是"**他为什么在这里**"——每个姿态都必须暗示一个**正在进行的目的**。

| # | 语义 | 定义 |
|---|---|---|
| 01 | `search` | 弯腰，双手插进齐膝的水里摸东西（在找） |
| 02 | `rise` | 正从水里直起腰，背还弯着，头刚抬起来 |
| 03 | `lookback` | 站在水里，上身已经转过来回头看，手臂垂着 |
| 04 | `recoil` | 后撤半步，重心在后脚，一只手臂横挡在脸前 |
| 05 | `shield` | 站稳，两脚分开踩实，小臂挡在脸前，另一只手在身侧握拳 |
| 06 | `hat` | 跪在浅水里，双臂把旧斗笠抱在胸前，低着头 |

## 六、服饰组（COST）标准清单 · 4 个

服饰是最容易被忽略、但最影响"是不是同一个人"的一环。
**同一套衣服必须能从四个角度被认出来**，否则跨镜头一定漂。

| # | 语义 | 作用 |
|---|---|---|
| 01 | `front` | 正面全身，双臂自然下垂，看清整体 |
| 02 | `side` | 侧面全身，看清轮廓与层次 |
| 03 | `back` | 背面全身，看清湿衣如何贴在背上、腰带怎么打结 |
| 04 | `detail` | 面料特写：湿麻布的织纹、水珠、干湿交界的颜色差、补丁的针脚、接缝的泥 |

> 阿月的服饰要点：**粗麻本色短褐 + 布腰带 + 赤脚 + 下摆沾泥**。
> 不要做成汉服/旗袍/现代衣，一旦漂成"好看的古代衣服"，穷苦渔家女的身份就没了。

## 七、动作模组（MOT）：能拆，但复用方式和你想的不一样

### 7.1 结论

**动作模组不能"贴"到新素材上**（视频模型每次调用都重新生成，不存在"动作迁移"接口）。
**但同一段动作片段可以"重用"**——通过剪辑手段，在多个位置发挥不同作用。

### 7.2 可复用的四种手法

| 手法 | 做法 | 复用倍数 |
|---|---|---|
| **镜像** | 水平翻转，左右互换 | ×2 |
| **变速** | 慢放 0.6× 做压迫感 / 抽帧快放 1.5× 做慌乱 | ×2 |
| **裁切重构图** | 全景片裁成中景/近景，同一段素材变成"新镜头" | ×2–3 |
| **换上下文** | 同一段"回头"，接在 A 前后是"听见"，接在 B 前后是"告别" | ×2 |

**四者叠加，一个模组平均可用 3–5 次。**

> **这正是库里肖夫效应的工程用法：同一段素材，靠前后文改变含义。**
> 所以动作模组不是"省素材"，是"**买表达力**"——同样的钱，买到的镜头数量翻几倍。

### 7.3 值得建的 6 个动作模组（每角色通用骨架）

| # | 语义 | 时长 | 复用场景 |
|---|---|---|---|
| 01 | `turn_head` | 4s | 听见声音回头 / 被叫住 / 告别 |
| 02 | `startle_back` | 4s | 被水浪掀退 / 被吓到 / 后退躲闪 |
| 03 | `walk_in_water` | 5s | 涉水前行（跟拍）/ 走近 / 离开 |
| 04 | `kneel_down` | 5s | 跪下 / 崩溃 / 捡东西 |
| 05 | `breath_hold` | 4s | 屏息（近景，几乎不动，只有胸口） |
| 06 | `reach_out` | 4s | 伸手 / 抓住 / 拦阻 |

**预算：6 个模组 × 4.5s ≈ 27 秒**，占日配额 5%。
一次建好，全片反复用。

## 八、拼装规则（组后怎么用）

一个镜头的生成流程固定为五步：

```
1. 选 EXP（这一刻什么心理）
2. 选 POSE（这一刻在做什么）
3. 叠加 COST（服饰/湿透程度，锁定一致性）
4. 合成为首帧（I2I，以 ID 定妆为参考）→ 人工确认"对"
5. 才调用视频（用 MOT 描述运动方向与幅度）
```

**关键纪律：第 4 步不通过，不许进第 5 步。**
每一次"先试试看"的视频调用，都是在烧一天里 1% 的配额。

## 九、配额预算表（一条 90 秒短片）

| 项目 | 次数 | 秒数 | 占日配额 |
|---|---|---|---|
| 动作模组（一次性投入，可跨集复用） | 6 | 27s | 5% |
| 正片 20 镜 × 1.3 次（允许 30% 重拍） | 26 | 130s | 26% |
| 备用/试错余量 | — | 40s | 8% |
| **合计** | | **197s** | **39%** |

**一集只用掉四成配额 → 一天可以推进两集半。** 这才是可持续的节奏。

## 十、验收清单（每批资产必过）

1. [ ] 表情组 8 张并排，是**同一个人**？
2. [ ] 表情组 8 张不看标签能认出情绪？
3. [ ] 动作组每张都能回答"他为什么在这里"？
4. [ ] 服饰组四视图是**同一套衣服**？
5. [ ] 有 `detail` 面料特写（没有就会漂成"好看的古代衣服"）？
6. [ ] 每个资产的 prompt 都带 I2I 参考（ID 定妆）？
7. [ ] 首帧人工确认通过，才允许调用视频？
