# 审美基准 v1

> 这不是"审美哲学"，是**每次生成前必须对照的检查表**。
> 写在最前面：AI 短剧的翻车 90% 不是模型不行，是**指令里没写清楚"不要什么"**。

---

## 一、视觉总定位

**一句话：伪纪录片式的写实电影质感，不是国漫，不是游戏 CG，不是古装剧棚拍。**

参照坐标（用来校准判断，不是拿来抄）：
- 罗攀的《老兽》、曹郁的《妖猫传》夜景——**单光源 + 大面积暗部**
- 韩片《哭声》的雨夜——**湿、脏、有颗粒**
- 不要参照：仙侠剧的柔光磨皮、B站国创的赛璐璐、游戏宣传片的锐利 HDR

**为什么定这个调**：Agnes 的图像模型在"写实人物 + 复杂光影"上表现明显强于"纯虚构生物"。蛟龙是虚构的，必须用**极度写实的摄影语言**去"骗"观众相信它是真的。一旦画面滑向动漫风，观众立刻知道你是在"看特效"，情绪就断了。

---

## 二、色彩方案（走蛟题材专用：冷夜 · 一点暖）

| 角色 | 色值方向 | 用在哪 |
|---|---|---|
| 主调 | 冷蓝 `#1B2A3E` ~ `#2E4A66` | 夜、江水、雨、天 |
| 强调 | 暖黄 `#E0A24C` ~ `#F2C879` | 渔火、油灯、龙鳞反光 |
| 危险 | 暗红 `#6B2020` | 血、雷光边缘、蛟眼 |
| 高光 | 冷白 `#D8E4EC` | 雨丝、水花、鳞片反光 |

**规则：整部片子里，暖色只能出现在"有生命/有情绪"的地方。**
冷蓝 = 世界（无情的、要吞人的）。暖黄 = 人（她要护住的那点东西）。这是视觉上的叙事。

**禁止**：
- 不要紫粉色调（仙侠剧味）
- 不要青橙对比拉满（好莱坞爆米花味）
- 不要高饱和（假）

---

## 三、镜头语言（横屏 16:9 专用）

### 安全区原则（AI 视频的硬约束）

| 景别 | 可用度 | 说明 |
|---|---|---|
| 特写 / 近景（人脸占 1/2 以上） | ⭐⭐⭐⭐⭐ **主力** | AI 最稳，情绪最强 |
| 中景（半身/全身） | ⭐⭐⭐⭐ 可用 | 交代动作，注意手部 |
| 全景 / 大远景 | ⭐⭐ **慎用** | 人物小、细节崩、AI 容易糊成一团 |
| 快速运动镜头 | ⭐ **基本别用** | 4–12 秒的 clip 撑不住，会拖影 |

**推论：短剧不要拍"大片感"，要拍"紧"的戏。** 全集 90 秒里，全景最多 2 个，剩下全是近景和中景。这不是妥协，是这类题材本身就该这么拍——**人在洪水面前，本来就只看得见自己面前三尺。**

### 机位与运动

- 默认**固定机位**或**极缓慢推进**（dolly in）。慢推进是最安全的"有电影感"运动。
- 手持感只在"逃跑/慌乱"时用，且幅度要小。
- **不要甩镜、不要快速摇、不要旋转**——AI 生成会崩。

### 构图

- 横屏优先**中心偏一侧**构图（人物不要在正中，留出负面空间给水和天）
- 水面 / 雨幕 / 雾气，永远保留一层"前景遮挡"（增加真实感）
- 地平线不要放正中，压在画面上 1/3 或下 1/3

---

## 四、光线原则（这是最容易被忽略、却最决定质感的一环）

**单光源为主。** 一个镜头里只允许一个主光源方向。

| 场景 | 光源设计 |
|---|---|
| 江边夜雨 | 唯一光源 = 远处一盏渔火/油灯，侧逆光，人物半张脸亮半张脸黑 |
| 蛟出水 | 唯一光源 = 闪电（硬光、冷白、瞬间过曝），其余全黑 |
| 晨光结尾 | 唯一光源 = 日出低角度侧光，暖黄，逆光勾轮廓 |

**禁止**：
- 不要"棚拍平光"（人脸平均亮、无立体感）
- 不要多光源均匀照明（AI 一遇到多光源就开始胡来）
- 不要"HDR 高动态"（暗部被提亮，就失去神秘感了）

---

## 五、材质与细节清单（写 prompt 时逐条对照）

写实感来自这些**小东西**，不是来自"8K、超高清"这类废话词：

- 湿发贴在脸颊上，几缕黏在嘴角
- 雨水顺着下颌线滴落
- 布料吸水后变深、贴身、褶皱沉重
- 皮肤有细小的毛孔和一点油光（**不要磨皮**）
- 蛟的鳞片：**湿润、半哑光、边缘有磨损和崩裂的缺口**（不是塑料反光）
- 水下：浑浊的、带泥沙的，能见度低（不是清澈见底）
- 呼吸在冷空气里变成白气

---

## 六、必须写进每个 prompt 的"负面词"

> 这是踩过坑总结的。Agnes 的图像模型默认会往"漂亮"走，必须往"真实"拽。

**中文负面段落（直接复制粘贴）：**
```
不要动漫风，不要游戏CG，不要塑料感皮肤，不要过度磨皮，不要高饱和，
不要棚拍平光，不要多人光源，不要现代元素，不要文字水印，不要镜像扭曲，
不要五官不对称，不要多余的手指
```

**视频额外加：**
```
保持人物五官和服装一致，不要变形，不要脸部扭曲，动作幅度小
```

## 七、Prompt 结构模板

写实图像/视频的 prompt，按这个顺序写，成功率最高：

```
[1 镜头与景别] 电影感近景特写 / 中景 / 过肩镜头
[2 主体与状态] 谁，什么年纪，什么表情，在做什么，身体的什么细节
[3 环境] 时间、天气、地点、前景是什么
[4 光线] 唯一光源在哪，什么颜色，怎么照在脸上
[5 材质细节] 湿发、水珠、衣料、皮肤
[6 质感收尾] 浅景深，35mm 胶片颗粒，写实电影质感
[7 负面] 上面那段固定负面词
```

**实测有效的例子**（本项目第 1 帧）：
> 电影感近景特写，一位二十岁上下的中国江南渔家少女，湿透的乌黑长发贴在脸颊，肤色偏冷白，眉毛自然，嘴唇清晰可见，穿着粗麻深色短褐，雨水顺着下颌滴落。她微微仰头看向镜头上方，眼神里有惊恐和一丝不忍。背景是暴雨夜的江面，远处有微弱的渔火，冷蓝色调，唯有一束暖黄光线从侧面照亮她半张脸和嘴唇。浅景深，面部占画面三分之二，正脸略微偏侧，嘴巴张开一点像要说话。写实电影质感，35mm 胶片颗粒

**注意这段里没有出现"8K"、"超高清"、"杰作"、"最佳质量"** ——这些词对写实风格没有帮助，反而会把画面推向塑料感。

## 八、判断标准：一张图/一段片子能不能用

拿到产物，按这个顺序问：

1. **第一眼有没有"这是 AI 做的"的感觉？** 有 → 弃
2. **脸崩了吗？** 五官不对称、牙齿糊、眼神空洞 → 弃
3. **光是不是平的？** 如果整张脸均匀亮着 → 弃，重新设计单光源
4. **有没有"多出来的东西"？** 多余的手指、莫名的影子、背景乱入 → 弃
5. **情绪对不对？** 这张脸有没有在"演"，还是只是"摆" → 决定留用或重做

**判定原则：宁可重做，不要将就。** 图像配额 4000 张/天，就为了让你能挑。一张"还行"的图，剪进片子里会让整段垮掉；而重做一张只需要 9 秒。
