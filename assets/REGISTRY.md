# 资产登记表 / Asset Registry

> 原则：**资产是唯一真源（single source of truth），镜头只是引用。**
> 改资产 → 所有引用它的镜头自动获得新版本；修一个局部 → 只升小版本号，不推翻重做。

---

## 一、编号规范

```
AST-<类型>-<三位序号>-<视图/角度>_v<主版本>.<次版本>
SHOT-<集号>-<镜号>_v<主版本>
```

| 类型码 | 含义 |
|---|---|
| CHAR | 角色（character） |
| PROP | 道具（prop） |
| CREATURE | 生物（虚构角色） |
| ENV | 环境/场景 |
| STYLE | 风格规范（色彩、LUT、镜头语言） |

**版本规则：**
- `v1.0` 首次生成
- **`v1.1` 局部修正**（改一处细节，如服装、表情、某个角度）← **优先走这条**
- `v2.0` 重做（结构性问题，无法局部修补）

> 用户明确要求：**"后面某个资产遇到一个小问题，稍微修一下就好，不必把所有的资产推翻。"**
> 所以默认动作永远是升小版本，只有根本性错误才升大版本。

## 八、如何局部修一个资产（操作流程）

1. 找到资产编号，比如 `AST-CHAR-001`
2. 只改它本身，**不动引用它的镜头文件**
3. 生成 `v1.1`
4. 只有需要让镜头体现变化时，才用新资产**重生成受影响的那几个镜头**（不是全部）
5. 在本表登记新版本 + 改了什么 + 影响范围

**反例（v1 犯的错）：** 为了让镜 3 的暗影正确，我重画了整张图；其实只需要修"暗影"这一处表述，其他元素本可以沿用。
